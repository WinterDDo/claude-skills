# MIXUE Bilingual Business Documents

## Overview

Reference skill for producing professional multilingual outputs across MIXUE's Americas franchise operations. Covers four language tracks (EN, ES, PT, ZH), document format variants, and franchise-specific conventions.

## Language Conventions

### Translation Quality Standards

| Track | Register | Notes |
|---|---|---|
| EN output | Formal business English | Correct Win's English errors inline |
| ES output | Formal Latin American Spanish | Mexico/Brazil regional usage preferred |
| PT output | Formal Brazilian Portuguese | Not European Portuguese |
| ZH output | Simplified Chinese, formal | For internal reports and HQ communication |
| PT to ZH | Strict word-for-word bilingual | Line-by-line parallel format |

### Bilingual Format Template

For any bilingual deliverable, use parallel blocks:

```
[English]
...content...

[Español / Português / 中文]
...content...
```

For line-by-line translation (PT to ZH):
```
Linha 1 original text.
第一行 对应翻译。

Linha 2 original text.
第二行 对应翻译。
```

## Formatting Rules

- No hyphens (-) or em dashes (--) in prose output; restructure sentences instead
- MIXUE store names: "MIXUE - [Location Descriptor]" (this hyphen format is the only exception)
- Responsibilities attributed to "the Americas Business Development department" not to Win personally
- Vary closing reflection adjectives each time: 开放、放松、自信、欢乐 or equivalents

## Format Variants by Output Type

When producing the same content in multiple formats, follow this adaptation logic:

| Format | Style | Key considerations |
|---|---|---|
| Email | Concise, direct | Subject line + 3 paragraph max, formal salutation |
| PPT | Bullet-point, visual | Max 5 bullets per slide, headline states the point |
| Word (.docx) | Structured, sections | Headings, numbered clauses for legal content |
| Excel (.xlsx) | Tabular, labeled columns | Headers in row 1, no merged cells for data rows |
| JSON | Machine-readable | camelCase keys, string values for all text fields |

## Franchise and Legal Document Conventions

### Entity References by Market

| Market | Legal entity type | Correct reference |
|---|---|---|
| United States | LLC | "MIXUE USA LLC" or operating entity name |
| Mexico | S. de R.L. de C.V. | Full form first use, "the Mexican entity" thereafter |
| Brazil | Ltda. | Full form first use, "the Brazilian entity" thereafter |

### FDD and Compliance Documents

- Attribute obligations to "the Franchisor" and "the Franchisee" (not to individuals)
- Financial figures: USD for US, MXN for Mexico, BRL for Brazil; always specify currency code
- When referencing Starbucks or McDonald's as comparable models, use "comparable franchise systems such as Starbucks and McDonald's"

### Common Document Types

- **FDD Item drafts**: Formal legal English, numbered items per FTC format
- **Franchise agreements**: Mirror-image bilingual clauses (EN left, local language right)
- **Onboarding templates**: Plain language, bulleted, available in local language only
- **HQ reports**: Chinese first, English summary appended

## Domain Expertise Context

When addressing AIGC or fresh-made beverage topics, respond from the perspective of an AI industry expert with consulting background in fresh-made beverage (comparable to Starbucks/McDonald's franchise systems).

Value learning from real franchise globalization failures: cite precedents from actual brand expansions when available rather than generic advice.

## Common Mistakes

| Mistake | Fix |
|---|---|
| Using dashes in prose | Rewrite: "high-quality" → "of high quality" |
| Attributing to Win personally | "Win will..." → "The Americas BD department will..." |
| European Portuguese phrasing | Use Brazilian equivalents: "você" not "tu", "ônibus" not "autocarro" |
| Repeating the same closing adjective | Rotate through 开放、放松、自信、欢乐 and equivalents |
| Generic franchise advice | Ground in specific comparable cases (Starbucks, McDonald's, Jollibee) |

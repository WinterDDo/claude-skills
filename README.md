# Claude Skills — WinterDDo

76 skills for Claude Code. Install in any session with one command:

```bash
curl -fsSL https://raw.githubusercontent.com/WinterDDo/win-skills/main/install.sh | bash
```

Restart Claude Code (or open a new session) and the skills auto-load.

> **New here? See the [Team Guide](TEAM-GUIDE.md)** — install on your computer, use the skills in your cloud projects, and how to trigger them.

## Provenance

Skills in this repo come from several places. Each retains its own license headers where present.

- `swiftui-patterns`: from ECC (github.com/affaan-m/ecc), MIT.
- `gstack-*`: from Garry Tan's gstack toolkit.
- `taste-skill` and its sibling design skills (`taste-skill-v1`, `gpt-tasteskill`, `brandkit`, `brutalist-skill`, `minimalist-skill`, `soft-skill`, `redesign-skill`, `stitch-skill`, `output-skill`, `image-to-code-skill`, `imagegen-frontend-web`, `imagegen-frontend-mobile`): from Taste Skill (github.com/Leonxlnx/taste-skill), MIT.
- Anthropic standard skills (`brainstorming`, `writing-plans`, `docx`, `pdf`, `pptx`, `xlsx`, etc.): from Anthropic's published examples.
- Other workflow and writing skills, and `distill`: original to this repo, MIT.

If you redistribute, preserve each skill's original attribution.
